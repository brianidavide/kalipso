# Kalipso palette — how it was derived

Generated by `tools/derive-palette.py`; rerun it to reproduce. Values feed `design/tokens.json` (group "site").

## Evidence

- Warm paper backgrounds measured on reference sites: Claude Code (Webby 2026) #FBFBF9 (L 0.988 C 0.003 h 106), Rijksmuseum Collection (Webby 2025) #EFEAE7 (L 0.940 C 0.007 h 53). Neutral tint hue = their mean, **80°**, at chroma 0.006: warm but never beige.
- Accents measured on reference sites: Google Chrome (PV 2024) #1A73E8 (h 258°), Reown (Webby 2025) #379DEF (h 247°), Affinity (PV 2026) #A7F175 (h 134°). Used only to break ties between equally good hues.
- Several winners use a dark neutral as the action colour (Claude Code, Google Antigravity, Tailscale, Shopify): the filled action stays ink.

## The "you are here" hue

Every hue in 5° steps was given the lightness it needs for 4.95:1 text on paper and on night (4.5:1 plus 10%), then scored (vividness / 0.2 + worst separation from error / 0.15). 8 hues scored within 3% of the best and count as equally good; among them the one closest to a reference accent wins: **260°**.
