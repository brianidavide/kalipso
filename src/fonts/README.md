# Atkinson Hyperlegible Next

Static TrueType instances, unmodified, from
[googlefonts/atkinson-hyperlegible-next](https://github.com/googlefonts/atkinson-hyperlegible-next)
at commit `7925f50f649b3813257faf2f4c0b381011f434f1` (`fonts/ttf/`): Regular, Italic, SemiBold, Bold and BoldItalic.
© 2020–2024 The Atkinson Hyperlegible Next Project Authors, under the SIL Open Font License 1.1 ([OFL.txt](OFL.txt)).

The app embeds them as its interface font and as the reader's default font. The website hosts its own
Latin subsets (`site/assets/fonts/`).
