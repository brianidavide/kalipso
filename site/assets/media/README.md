# Product recording

These are actual captures of the Linux Qt application, using its `--demo` sample script and clean settings. Progress is advanced with `Ctrl+Right`, not speech recognition. The recording has no audio and never opens a microphone. It shows the editor, opens the reader, advances the script and hides the reader.

`native-reader.webp` and `native-editor.webp` are lossless encodings of the application's `--screenshot` output. The two video files show the same 13-second X11 recording, encoded as H.264 and VP9 for browser compatibility. No interface elements were composited into the recording. These images do not claim to show macOS, Windows, GNOME Shell or Plasma.

The page uses explicit playback controls and a static poster, with no autoplay. Diagnostic screenshots and raw recordings are not part of the website distribution. Refresh these curated captures when the shown interface changes.
